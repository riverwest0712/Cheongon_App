소셜 로그인 구현(클라이언트 ID 등록)

현재 구현 방식: 
이메일 확인 회원 있으면 바로 로그인 
회원 없으면 즉시 user테이블에 인서트

변경할 회원가입 방식:
구글 토큰 검증 후 아이디 조회 
있으면 바로 로그인
신규 등록자는 테이블에서 사용자 안 만듦
구글 회원가입 완료 화면(여기서 닉네임 받기 + 약관 동의)

DB 일반회원/구글 회원 분리 

신규: 
구글 계정 선택 -> 회원가입 완료 -> 닉네임, 약관 동의 -> 가입 완료 -> 메인 화면

기존:
로그인 -> 구글 계정 선택 -> 메인 화면

AI 면접 질문 생성 로직
질문 생성 -> 로그인 확인 -> 필수값 검사 -> 자바 요청 객체 생성 -> 서버 POST요청 -> 서버 입력 검사 -> 제미나이 1차 호출 -> 네이버 뉴스 검색 정리 -> 분류별 문항 수 계산 -> 제미나이 2차 호출 -> 20문항 생성 -> 질문, 출처, 안내 반환 -> 결과 카드 표시

InterviewQuestionActivity - 면접 화면 담당 
지원 직무 100
경력 수준 80
채용공고, 필요 역량 8000
자기소개서, 주요 경험 12000
지원 회사, 산업 300

InterviewQuestionRequest
입력값 5개를 묶음

InterviewQuestionResponese - 서버에서 받은 결과 처리(생성된 질문 목록, 질문 내용, 출처, 기사 제목, 링크, 날짜 등)

interview.js - openai 면접 질문 생성
