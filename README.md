# 🌱 청온

### 나에게 맞는 청년 정책을 찾고, 취업 준비까지 이어가는 청년 지원 플랫폼

청온은 나이·거주지·소득·재직 상태 등 개인 조건을 바탕으로 청년 정책을 추천하는 Android 서비스입니다. 흩어져 있는 정책을 탐색하고, 관심 정책의 신청 일정을 관리하며, 커뮤니티와 AI 도구를 통해 취업 준비를 이어갈 수 있도록 구성했습니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 개발 기간 | 2026.07 ~ 2026.11 예정 |
| 개발 인원 | 5명 |
| 플랫폼 | Android |

## 서비스 이용 흐름

```text
회원가입 및 로그인
        ↓
개인 조건 입력
        ↓
맞춤 정책 추천 · 상세 정보 확인
        ↓
관심 정책 저장 · 신청 일정 관리
        ↓
커뮤니티 · 정책 챗봇 · 취업 준비 도구 활용
```

## 주요 기능

### 맞춤 정책 추천
- 나이, 거주지, 소득, 재직 상태 등 사용자 조건을 저장합니다.
- 사용자 정보와 정책 조건을 비교해 추천 결과와 적합도 점수를 제공합니다.
- 정책 상세 내용과 신청 관련 정보를 확인할 수 있습니다.
- 소득계산기를 통해 조건 입력을 돕습니다.

### 관심 정책 및 일정 관리
- 관심 있는 정책을 북마크에 저장하고 모아볼 수 있습니다.
- 캘린더와 D-Day 표시로 정책 신청 일정을 확인합니다.
- 마감 여부와 상시 신청 등 정책의 일정 상태를 표시합니다.

### 커뮤니티
- 게시글과 댓글을 작성·수정·삭제할 수 있습니다.
- 좋아요를 통해 관심 있는 게시글에 반응할 수 있습니다.
- 작성한 게시글·댓글과 좋아요를 누른 게시글을 모아봅니다.

### AI 지원 도구
- **청냥이 챗봇:** 질문에 맞는 정책 정보를 찾고 서비스 이용을 안내합니다.
- **자기소개서 첨삭:** 작성한 자기소개서를 바탕으로 피드백을 제공합니다.
- **면접 질문 생성:** 지원 직무와 역량, 자기소개서 등 입력 정보를 바탕으로 질문을 생성합니다.

### 계정 및 알림
- 일반 회원가입·로그인과 Google 소셜 로그인 기능을 구성했습니다.
- 회원정보 수정, 설정, 회원탈퇴 기능을 제공합니다.
- 알림 조회와 읽음·삭제 상태를 관리합니다.

### 취업 도구 이용권
- 취업 도구 이용권과 Toss 테스트 결제 흐름을 구성했습니다.
- 서버에서 주문·금액·승인 응답을 검증하고 이용권 상태와 연결합니다.
- 현재 테스트 결제 기능이며 실제 유료 서비스 운영을 의미하지 않습니다.

## 개발 및 개선 방향

- 다양한 사용자 조건 조합에 대한 정책 추천 검증
- 로그인·이용권·결제 흐름의 인증 처리와 예외 상황 개선
- 중복 결제 요청, 취소, 네트워크 실패 시나리오 검증
- 공통 UI 재사용 및 화면과 데이터 처리 로직의 분리
- 실제 기기에서 주요 서비스 흐름의 통합 테스트

## 이용 안내

- 정책 추천 점수는 참고용 적합도이며, 실제 신청 자격·기간·선정 기준은 해당 기관의 공식 공고를 확인해야 합니다.
- AI 응답과 첨삭 결과는 참고 자료로 활용하며, 정책의 최신 내용은 공식 정보를 기준으로 확인합니다.
