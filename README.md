# 청온 (Cheongon-App)

### 나에게 맞는 청년 정책을 찾고, 취업 준비까지 이어가는 청년 지원 플랫폼

청온은 나이, 거주지, 소득, 재직 상태 등 개인 조건을 바탕으로 청년 정책을 추천하는 Android 애플리케이션입니다.

흩어져 있는 청년 정책 정보를 탐색하고, 관심 정책의 신청 일정을 관리하며, 커뮤니티와 AI 기반 도구를 통해 취업 준비를 이어갈 수 있도록 구성했습니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 청온 (Cheongon) |
| 개발 기간 | 2026.07 ~ 2026.11 |
| 개발 인원 | 5명 |
| 플랫폼 | Android |
| 데이터베이스 | MySQL |

## 서비스 이용 흐름

```text
회원가입 및 로그인
       ↓
개인 조건 입력
       ↓
맞춤 정책 추천 및 상세 정보 확인
       ↓
관심 정책 저장 및 신청 일정 관리
       ↓
커뮤니티 및 AI 취업 준비 도구 활용
```

## 주요 기능

### 1. 맞춤 정책 추천
- 나이, 거주지, 소득, 재직 상태 등 사용자 조건 입력
- 사용자 정보와 정책 지원 조건 비교
- 정책 추천 결과 및 적합도 점수 제공
- 정책 상세 정보 및 신청 관련 정보 확인
- 소득계산기 제공

### 2. 관심 정책 및 일정 관리
- 관심 정책 북마크 저장 및 조회
- 캘린더를 통한 정책 신청 일정 확인
- D-Day를 활용한 신청 마감일 확인
- 정책별 신청 상태 표시

### 3. 커뮤니티
- 게시글 작성, 조회, 수정, 삭제
- 댓글 작성 및 관리
- 게시글 좋아요
- 내가 작성한 게시글과 댓글 조회
- 좋아요한 게시글 모아보기

### 4. AI 지원 도구
- 청냥이 챗봇을 통한 정책 정보 검색 및 서비스 안내
- 자기소개서 첨삭 기능
- 지원 직무와 입력 정보를 바탕으로 면접 질문 생성

### 5. 계정 및 알림
- 회원가입 및 로그인
- Google 소셜 로그인 기능 구성
- 회원정보 수정 및 회원탈퇴
- 알림 조회 및 읽음·삭제 상태 관리

### 6. 취업 도구 이용권
- 취업 도구 이용권 관리
- Toss Payments 테스트 결제 흐름 구성
- 주문 및 결제 승인 정보 검증

※ 결제 기능은 테스트 환경을 기준으로 구성되어 있으며 실제 유료 서비스 운영을 의미하지 않습니다.

## 프로젝트 개발 방향

- 사용자 조건에 따른 맞춤 정책 추천 기능 구현
- 정책 정보와 사용자 데이터의 연동
- 커뮤니티를 통한 사용자 간 정보 공유
- AI 기반 정책 안내 및 취업 준비 기능 제공
- Android 앱과 서버 간 데이터 통신 구현

## 이용 안내

- 정책 추천 점수는 참고용 적합도이며, 실제 신청 자격 및 선정 여부는 해당 기관의 공식 공고를 확인해야 합니다.
- AI 응답과 첨삭 결과는 참고 자료로 활용하며, 정책의 최신 내용은 공식 정보를 기준으로 확인합니다.
