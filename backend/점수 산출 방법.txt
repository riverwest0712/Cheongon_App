점수 산출 방법

1차 필터
1) 지역  2) 나이  3) 성별  4) 병역여부  5) 재직여부
>> 하나라도 불일치 시 0점
>> 전부 일치 시 2차 필터로 넘어감, + 50점

2차 필터
1) 소득 계산 방법 - 예) 정책 최대 소득 : 3000만원
                             사용자 최대 소득 : 2800만원
                             차이 : 200만원
                             비율 : 200 / 3000 = 0.066
                             >> 1 - 0.066 = 0.934
                             소득 점수 : 0.934

* 정책 기준이랑 사용자 소득 차이를 비율로 계산해서 자연스러움.

2) 가구 특성 - 맞으면 1, 틀리면 0
3) 취약계층 여부 - 맞으면 1, 틀리면 0

최종점수
최종점수 = 50 + (코사인 유사도 x 50)

위 결과를 토대로 상위 10개까지의 정책을 보여줌. 0점이면 안보여서 10개미만일 수 있음.
